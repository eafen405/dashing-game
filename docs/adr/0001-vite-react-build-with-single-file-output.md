# 改用 Vite + React 构建，但产物仍是单文件可离线运行

原项目承诺"零依赖、零构建 —— 整个游戏就是一个 `source.html`，用浏览器打开即可运行"。本次重构放弃这条产品承诺：仓库改为标准 Vite + React 项目，并引入 TypeScript、Vitest、ESLint。构建产物仍保持单文件形态 —— 用 `vite-plugin-singlefile` 把全部 JS/CSS 内联进单个 `dist/index.html`，双击即可离线游玩，最高分继续存放在 `localStorage`。

**为什么走这条中间路线**：开发期的类型检查与单元测试是本次重构的主要收益来源（把 2314 行命令式 JS 拆成可测试的纯逻辑），完全放弃构建工具就拿不到这些收益；而"发给别人一个文件就能玩"是这个游戏实际的传播方式，直接改成需要服务器托管的站点会砍掉一条主要路径。所以保留构建，但保留单文件产物。

**后果**：`source.html` 中"零依赖、零构建"的表述不再成立，README 需相应改写。`file://` 下的 WebGL 上下文与 `localStorage` 可用性因浏览器而异，需在实现阶段实测并准备降级路径。

**现状**（2026-10）：README 已按本决策改写 —— 删掉"零依赖、零构建"的表述，改为"标准 Vite + React 工程 → 单文件产物"，并补齐开发 / 构建 / 校验 / 测试流程与四层架构说明。`file://` 下的可用性已实测：`npm run verify` 的浏览器检查（Chromium）确认产物单文件自包含、画布正常渲染、`localStorage` 可读写、零外部网络请求。Firefox / Safari 仍未在本机实测。
