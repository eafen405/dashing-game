## Native player

`--dashing-smoke` renders actual windows through Direct3D 11 and saves nonblank
screenshots. Hidden Unity windows skip frame submission on this machine, so the
visual check uses a real visible window. It validates:

- menu, actual running scene, both character renderers and transparent animation;
- paused clock stays frozen;
- hold head / duration / completion and soul hit leave the body holding;
- naturally reached twins, burn and FEVER in a seeded 3-star run;
- forced short FEVER expiry restores presentation within 0.7 seconds;
- 1280×720 → 720×1000 → 1280×720 resizing and narrow HUD;
- game-over and clean restart.

`Tools/Test-Input.ps1` sends real keys and mouse clicks only after verifying that
the foreground window is the newly launched game. It scales coordinates using
the actual Windows client rectangle and per-monitor DPI context. Checks cover
Enter, W/S, P/Esc, frozen pause, mouse upper/lower half, pause/continue/menu/start
buttons, character and difficulty selection. **16 checks pass**.

Machine-generated output is ignored under `unity/TestResults/`, not checked in.

## Character-presentation follow-up (2026-10-25)

The first native version incorrectly selected riding only on the top lane and
used standing breathing for ground movement. It also omitted the source player
motion curves and several feedback layers. The follow-up restores:

- lower-rail 9-frame riding / 12 fps with continuous frame blending; menu breathing;
- frozen riding pose during pause, rather than switching to the standing quad;
- parabolic upper jump, gravity after a downward interruption, landing compression
  / dust ellipse, 0.62-second twin jump and slam, hold waiting / 0.24-second swings;
- HP track / remaining arc, ground shadow / light, hurt red flash, FEVER gold arcs;
- burn rim, hair-tip flames, red-black comet tails, rising smoke / floating embers
  and scythe crescents; all instantiated once and reused;
- filled, pulsing judgment rings with soft / sharp outlines, center / direction
  arrow and labels tied to layout and pointer mode. Four-sample MSAA smooths meshes.

`PresentationChecks.Run` passes **18 targeted assertions**. The native smoke adds
**12 renderer / pose checks** and seven screenshots (`11-…` through `17-…`),
including two distinct ground riding frames. Actual screenshots were inspected
for riding, jump apex, twin jump, burning ride / attack, paused hold and portrait
layout. Native checks also confirm the new FEVER arcs disappear after expiry.

Rules still pass **3162 assertions / 408 TypeScript snapshots / 8 replays**.
Actual Windows keyboard / mouse checks still pass **16 checks**. The web code and
its earlier animation / FEVER cleanup fixes are unchanged by this follow-up.
Menus, enemy artwork and remaining scene treatments still use the native port's
presentation; this is not a claim of complete visual parity with Pixi.
