# Release closeout

Complete the three follow-ups from the project review: native per-rail key
editing, an evidence-based Web bundle budget, and a verified local Git checkpoint.
Keep offline single-file delivery, original artwork, game rules and timing intact.

## Acceptance

- Unity supports 1–3 editable keys per rail, duplicate/reserved-key rejection,
  removal, defaults, presets, cancellation and persistence.
- Editing never starts, pauses or strikes; pause/hold and pointer controls work.
- Bundle composition is measured; remove unused runtime features where safe and
  report artwork separately instead of hiding an exceeded historical budget.
- Web checks, native rules/build and actual key editing/input checks pass.
- Record results, include source/assets and exclude generated files in a local
  commit. Do not push to a remote.
