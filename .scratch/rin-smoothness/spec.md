# 凛的动作连贯性

用户反馈：凛动作看起来卡顿，希望先做一版改善。

## 范围

- 保留现有原画、朝向、角色大小和战斗规则。
- 修复呼吸循环混入起手姿势、稀疏原画硬切、长按循环缺少收势的问题。
- 使用同一个四边形混合相邻原画的预乘 alpha；不新增离屏滤镜、中间图片或逐帧对象。
- 骑乘仍为九帧 / 0.75 秒，出招仍为 0.44 秒，长按仍为 0.24 秒一循环。
- 只修改本地，未提交或推送远端。

## 验收记录

- 36 个测试文件、500 项单元测试通过，包含六项新增动作采样测试。
- 浏览器实际运行约 50 秒：击破 41 只、得分 16500，完成一次长按并触发灵魂代打；
  覆盖骑乘、上下轨出刀、燃魂，无页面异常或 WebGL 控制台错误。
- GPU 实际像素验证：红 / 蓝原画混合中点为 RGBA(128, 0, 128, 255)，
  身体不因双图淡化而闪暗；实例释放路径正常。
- 暂停冻结原画时钟并保留骑乘姿态；构建、类型检查、lint、自包含验证与冒烟通过。
- 手机实机体感尚待用户试玩；桌面浏览器结果不作为手机帧率结论。
