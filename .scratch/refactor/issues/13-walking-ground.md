# 13 — 地面与行走：人在陆地上前进，路上遇到怪

Status: resolved
Blocked by: (none)

## 需求

1. 增加看得见的地面，角色不再悬在空处，而是走在陆地上。
2. 画面读成「角色持续向前走、途中遇到怪」，而不是「怪从右边飞向站着的人」。
3. 只改表现，不改打击 / 漏怪 / 受伤的规则。

## 实现

- 新增 `canvas2d/ground.ts`：
  - `FEET_OFFSET_R = 0.94`、`laneGroundY()` 统一「脚底 / 轨道光带」的几何；
    `PlayerView`、`RailsView`、怪物阴影、防线都改用它，避免各画各的。
  - 地面上缘贴着顶轨脚底，向下铺满画面；深蓝渐变 + 地平线 + 五道层理。
  - 96 个随世界左移的碎石 / 石块 / 土斑 / 草簇，近大远小；
    位移用 `now * scrollSpeed`，和怪物移速完全一致，暂停 / 结束时冻结。
  - 角色待机高度铺一条柔和土路色带，让脚底落在路面上。
- `FrameView.scrollSpeed`（= `speedNow(now, diffLevel)`），由 `GameSession` 每帧写入；
  `FrameContext` 同步缓存 `phase` / `now` / `scrollSpeed`。
- 走路：
  - `PlayerView` 在 `phase === 'running'` 且未出招 / 未长按 / 未双生跳砸时持续摆腿，
    `walkPhase = now * 13`，换轨时步幅随位移叠加。
  - 步态带身体起伏、腿的轮廓光和身后淡尘；脚下的平台光从「悬浮平台」改成
    贴脚底的接触光，避免陆地上还像踩着反重力的板。
- 轨道 / 怪物：
  - 轨道光带与刻度移到角色脚底，刻度按世界速度滚动；角色真的站在轨道上。
  - 怪物去掉向玩家拖曳的速度尾迹，改为落在地面线上的椭圆阴影（长条怪是同款长影）。
  - 防线从顶轨地面线延伸到底轨地面线，作为「会被漏怪撞到」的接触平面。

## 验证

- 190 tests / 19 files 全绿；typecheck、lint、build、single-file 校验通过。
- Playwright 连续帧截图确认：腿在走、地面碎石在左移、人物与怪物阴影贴地。
- 暂停 400 ms / 1000 ms 两张截图的底部地面区域像素差为 0，地面确实冻结。
- 30 秒实际游玩无 console error / pageerror；分数、暴击 / 普攻计数正常累计。
