# 17 — 判定框挪到棒尖，去掉剑气，木棍加长

Status: resolved
Blocked by: (none)

## 需求

1. 打击判定框离角色太远，看起来像木棍根本打不到怪。
2. 不要飞出去的剑气 / 刀光，改成木棍实打实敲中。
3. 判定框要落在木棍攻击范围之内，木棍可以适当加长。

## 实现

- 新增共享几何（单位 playerR）：`CLUB_PIVOT_X_R = 0.1`、`CLUB_GRIP_R = 0.42`、
  `CLUB_LEN_R = 2.55`，合计 `CLUB_REACH_R = 3.07`。判定框和渲染共用同一组常量。
- `computeLayout()`：`hitX = playerX + playerR * CLUB_REACH_R`，
  判定框中心就是棒尖的最大水平距离（900 宽下 345.9 → 247.52）。
  `zoneHalf / critHalf` 不变，暴击率仍约 50%；漏怪线也没动，实际可打击窗口与之前接近。
- 木棍从 1.24R 加长到 2.55R（约 57 → 117 px），棒身、高光、击打闪光、
  挥棒残影和棒端弧线全部跟着新长度走。
- 去掉剑气：
  - `SlashView` → `ImpactView`：不再画飞行新月 / 打击点刀光 / 竖向光柱，
    只在接触点画一圈短冲击环 + 中心白闪 + 几点木屑。
  - 效果事件 `slash` 改名 `impact`，去掉不再需要的 `x0`。
  - 删除长按时的能量冲击带（`drawHoldBeam`），长按改为纯木棍连续敲击。
- 起点判定 / 长按起手 / 双生窗口都读新的 `hitX`，规则不变。

## 验证

- 194 tests / 19 files 全绿；typecheck、lint、build、single-file 校验通过。
- 布局用例更新：900×500 下 `hitX = 247.52`；窄屏 129.76、宽屏 261.22，
  都只跟棒尖走，不再被屏幕宽度拉到 430。
- 截图确认：待机时棒尖就在判定圈左缘附近，挥击时棒子穿过圈心；
  命中的特效留在接触点，没有飞行刀光。
- 30 秒实际游玩：84 次点击、4800 分、230 血、10 暴击 / 8 普攻，无 console error。
